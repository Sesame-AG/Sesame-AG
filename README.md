## 🤖 AI 辅助构建声明

本仓库的 **CI/CD 工作流、签名配置、自动化脚本** 均由 AI 助手（豆包）协助编写与配置：

- 自动同步上游代码 → 自动签名构建 → 自动发布 Release → 邮件通知
- 自定义签名证书由 AI 协助生成
- 整个流水线在 GitHub Actions 上运行，每 3 天自动执行一次

**AI 负责写代码，人负责做决策和承担后果。** 工作流中的每一步配置都经过人工确认，但 AI 不保证构建产物的安全性、稳定性或适用性。
